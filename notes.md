yannis: "I did some quick experimentation with the HPR and TPO operators for visibility and silhouettes. They are easy to implement, but the results are very sensitive to the parameter you need to specify. It looks like that parameter depends strongly on: 1) density of points; 2) distance of viewpoint from the point cloud. I think we will need to empirically figure out some heuristic for selecting this parameter.
I didn't see a huge difference between using the various "inversion functions" suggested in the HPR papers (linear versus exponential versus natural exponential). Exponential seems to have a smaller range of values to explore, so maybe that's the one to use."
